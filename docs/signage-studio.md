# Signageと表示内容の管理

トップページの「システムを利用する」からControllerを開きます。同じアカウントのSignageは、1つのController一覧に集約されます。アプリ上のSignage台数制限はありません（Supabaseの契約上の容量・接続数は適用されます）。

## 既存環境の更新

Supabase SQL Editorで `supabase/studio-upgrade.sql` 全文を実行します。既存の端末・表示設定・操作履歴を保持し、何度でも実行できます。新規環境では先に `supabase/setup.sql` を実行してください。

このSQLは初回／再接続を記録する `dtis_connect` と、非公開Storageバケット `dtis-media` を用意します。Storageの読み取り・追加・削除は同じアカウントのフォルダー内に限定します。公開キーだけではファイルも端末も読み取れません。サービス用の秘密キーは不要です。

## Signageの追加と操作

1. Controllerの「Signageを追加」でデバイス名を入力します。
2. 発行された専用URLを、その表示用デバイスで開きます。同じアカウントでログインしてください。
3. Controllerの接続通知に「新しいSignageが接続しました」が表示されます。以前接続した専用URLを開き直すと「既存のSignageが再接続しました」と表示されます（通常5秒以内）。
4. 右上の本棚型のSignage一覧で操作する画面を選択し、表示内容を編集して「Signageに反映して記録」を押します。別のSignageの表示内容は変更されません。

各画面には異なる専用URLを使ってください。同じ専用URLを同じブラウザーの複数タブで開くと、重複した操作・保存を防ぐため、先に開いているタブの終了を待ちます。通常の `/signage/` を初めて開く場合は、そのブラウザー用のSignageを自動登録します。ログイン情報を削除した場合は、以前の専用URLを使うと同じ端末として再開できます。

Controllerの背景は `#c8c8c8` です。右上のSignage一覧で端末を選択すると「クイック設定」「エディターで細かく編集」「今の様子（画面共有）」を表示します。歯車ボタンは廃止し、表示停止／再開、デバイス名、交通情報の更新、保存済み設定の再読込、専用URLは「クイック設定」のデバイス設定へ移しました。

「今の様子」は、実際にSignageが描画した表示画像を約2秒間隔で受信します。「大きく表示」で拡大できます。Signageの「映像で画面を共有」を利用できるブラウザーでは、許可後にWebRTCで動画を共有できます。iPadなど画面共有APIに対応しない環境では画像プレビューを使用します。

## グリッド付きレイアウトエディター

「エディターで細かく編集」では16:9の画面に、発車案内・スクロール文・テキスト・写真／動画・時計のパーツを配置できます。ドラッグや矢印キーで2%刻みに移動し、右下のハンドルまたは「位置と大きさ」でサイズを変更します。複製・削除・前後の重なり順・元に戻す／やり直すに対応しています。1画面につき50パーツまで配置できます。

複数の方面をまとめて表示する発車案内は、各方面を均等な領域に分け、文字や時刻表全体が収まるよう縮小します。ページが複数ある場合は、エディター上部の「編集する表示ページ」で2ページ目以降の方面も選択できます。このページ選択はプレビューだけに反映され、Signageの自動切り替え設定は変わりません。

文字や発車案内内の路線名・時刻・行き先を選ぶと、吹き出しメニューで書体・文字サイズ・色・太字・斜体・下線・文字揃え・点滅を変更できます。路線名や方面の表記は直接上書きでき、空欄に戻すと交通データの表記に戻ります。発車時刻・行き先は交通データを保持したまま書式を変更します。スクロール文の部分装飾は、パーツ選択後の「スクロール文の文字・点滅を編集」から設定できます。

発車案内は「登録した路線を自動で切り替え」または特定の路線・方面、写真／動画は全件の順次表示または特定のコンテンツを指定できます。編集後は「Signageに反映して記録」で保存します。各Signageのレイアウトは独立しています。「標準レイアウトに戻す」で通常の自動配置を使えます。

## 遅延・運転見合わせ

「クイック設定」の「遅延・運転見合わせ」で、路線・方面ごとに通常運行／遅延／運転見合わせを指定します。遅延は1〜360分を入力でき、変更後の発車時刻を黄色、その下に「定刻 HH:mm ＋N分」を表示します。発車済みの判定と並び順にも遅れ時分を使い、日付をまたぐ便にも対応します。運転見合わせでは発車時刻表を見合わせメッセージに置き換えます。

これはControllerから保存する手動の運行状況です。運行が戻ったら「通常運行」に戻して保存してください。案内文は遅延・見合わせ時のみ入力できます。

施設名の入力は廃止しました。Controllerでは「メイン画面」などのデバイス名で管理し、Signageの上部には表示中の路線の駅名を自動表示します。複数の駅を登録した場合は、案内ページと一緒に駅名も切り替わります。

「路線を追加する」では駅・停留所の名前や駅番号で検索するか、「マップから選ぶ」で地図上のマーカーを選び、その駅の路線を選択します。地図は拡大・縮小とドラッグ移動に対応します。座標のない駅・停留所は名前検索から追加してください。

## 書体とコンテンツ

- ゴシック体：BIZ UDPゴシック。明朝体：BIZ UDP明朝 Regular。英数字はInter / Helveticaです。日本語フォントをサイトと一緒に配信するため、iPadへのフォントのインストールは不要です。明朝の疑似Boldは生成しません。
- 追加フォント：WOFF2 / WOFF / TTF / OTF、10MB以内。ウェブ配信可能なライセンスのファイルを選びます。
- 写真：PNG / JPEG / WebP / GIF / AVIF、20MB以内。
- 映像：MP4 / WebM / MOV、50MB以内。音声なしで自動再生します。端末が対応するコーデックが必要です。iPad向けにはMP4のH.264を使用してください。
- 1画面に写真・映像を合計20件まで配置し、順番・表示秒数・交通案内との並列／交互表示を設定できます。動画は指定秒数または動画終了で次へ進みます。交互表示は交通案内15秒、コンテンツ15秒です。

ファイルの代わりにHTTPSの直接URLも指定できます。動画サイトのページURLは使用できません。外部フォントは配信元がCORSを許可する必要があります。保存操作では最初のコンテンツがSignageで読み込めるか確認し、読み込めない場合は確定前の設定へ戻します。後続のコンテンツの再生可否は各表示時に確認されます。

「表示から削除」は表示設定から取り除く操作です。他のSignageや保存済み履歴で参照するファイルを壊さないよう、Storageの実ファイルは残します。不要になったファイルは、利用先がないことを確認してSupabaseのStorage管理画面から削除できます。

## 移動時間

「手動で設定」では駅・停留所までの時間と乗車までの余裕時間を入力します。「GPSから徒歩時間を推定」では、Signage設置場所でControllerの現在地取得ボタンを押します。保存する位置はその時点の位置で、自動追跡はしません。別の場所から操作するときは緯度・経度を手動で入力できます。

駅までの直線距離に迂回係数1.3を掛け、指定した徒歩速度で時間を推定します。手動の追加時間と乗車までの余裕時間を加え、その時刻以降に発車する便を表示します。実際の徒歩経路・信号・階段・入口位置には対応していないため、設置場所に応じて余裕時間を調整してください。駅の座標が取得できない場合は手動時間だけを使い、その旨をSignageに表示します。

## スクロール文面と切り替え効果

エディターに案内文を直接入力すると、文字の色・太さ・書体・点滅をその場で確認できます。装飾したい文字を選択し、ツールバーの設定を指定して「選択した文字に適用」を押します。部分編集や貼り付けでも前後の装飾は保持されます。「元に戻す」「やり直す」とキーボードのCtrl/⌘+Zに対応しています。改行はSignageでは空白として表示します。

文全体の文字サイズは小・中・大、速度はゆっくり・標準・速いの3段階です。選択した区間の末尾が画面中央に来ると指定秒数停止します。「選択の装飾を解除」で一部だけ、「文字の装飾をすべて解除」で文全体の装飾を戻せます。文字数は2000文字、装飾区間は200までです。

「発車時のアニメーション」は便が発車案内から消えるときの効果、「画面切り替えのトランジション」は路線・言語・写真／動画が切り替わるときの効果です。それぞれ上にスライド／フェード／立体フリップ／パタパタ表示／ズーム／なしを独立して選べます。端末の「視差効果を減らす」など動きを抑える設定が有効な場合は、切り替え効果・点滅・スクロールを止め、文面を静止表示します。
