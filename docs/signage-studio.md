# Signageと表示内容の管理

トップページの「システムを利用する」からControllerを開きます。同じアカウントのSignageは、1つのController一覧に集約されます。アプリ上のSignage台数制限はありません（Supabaseの契約上の容量・接続数は適用されます）。

## 既存環境の更新

Supabase SQL Editorで `supabase/studio-upgrade.sql` 全文を実行します。既存の端末・表示設定・操作履歴を保持し、何度でも実行できます。新規環境では先に `supabase/setup.sql` を実行してください。

このSQLは初回／再接続を記録する `dtis_connect` と、非公開Storageバケット `dtis-media` を用意します。Storageの読み取り・追加・削除は同じアカウントのフォルダー内に限定します。公開キーだけではファイルも端末も読み取れません。サービス用の秘密キーは不要です。

## Signageの追加と操作

1. Controllerの「Signageを追加」でデバイス名を入力します。
2. 発行された専用URLを、その表示用デバイスで開きます。同じアカウントでログインしてください。
3. Controllerの接続通知に「新しいSignageが接続しました」が表示されます。以前接続した専用URLを開き直すと「既存のSignageが再接続しました」と表示されます（通常5秒以内）。
4. Signage一覧で操作する画面を選択し、表示内容を編集して「Signageに反映して記録」を押します。別のSignageの表示内容は変更されません。

各画面には異なる専用URLを使ってください。同じ専用URLを同じブラウザーの複数タブで開くと、重複した操作・保存を防ぐため、先に開いているタブの終了を待ちます。通常の `/signage/` を初めて開く場合は、そのブラウザー用のSignageを自動登録します。ログイン情報を削除した場合は、以前の専用URLを使うと同じ端末として再開できます。

右上の「デバイス設定」には、接続状態、最終応答、ライブ画面、表示停止／再開、デバイス名、交通情報の更新、Supabaseからの再読込、専用URLをまとめています。ライブ画面はこのメニューを開いている間に受信します。通常は表示画像を定期更新します。Signageの「映像で画面を共有」を利用できるブラウザーでは、許可後にWebRTCで動画を共有できます。iPadなど画面共有APIに対応しない環境では画像プレビューを使用します。

## 書体とコンテンツ

- ゴシック体：BIZ UDPゴシック。明朝体：BIZ UDP明朝 Regular。英数字はInter / Helveticaです。日本語フォントをサイトと一緒に配信するため、iPadへのフォントのインストールは不要です。明朝の疑似Boldは生成しません。
- 追加フォント：WOFF2 / WOFF / TTF / OTF、10MB以内。ウェブ配信可能なライセンスのファイルを選びます。
- 写真：PNG / JPEG / WebP / GIF / AVIF、20MB以内。
- 映像：MP4 / WebM / MOV、50MB以内。音声なしで自動再生します。端末が対応するコーデックが必要です。iPad向けにはMP4のH.264を使用してください。
- 1画面に写真・映像を合計20件まで配置し、順番・表示秒数・交通案内との並列／交互表示を設定できます。動画は指定秒数または動画終了で次へ進みます。交互表示は交通案内15秒、コンテンツ15秒です。

ファイルの代わりにHTTPSの直接URLも指定できます。動画サイトのページURLは使用できません。外部フォントは配信元がCORSを許可する必要があります。保存操作では最初のコンテンツがSignageで読み込めるか確認し、読み込めない場合は確定前の設定へ戻します。後続のコンテンツの再生可否は各表示時に確認されます。

「表示から削除」は表示設定から取り除く操作です。他のSignageや保存済み履歴で参照するファイルを壊さないよう、Storageの実ファイルは残します。不要になったファイルは、利用先がないことを確認してSupabaseのStorage管理画面から削除できます。

## 移動時間

「手動で設定」では駅・停留所までの時間と乗車までの余裕時間を入力します。「GPSから徒歩時間を推定」では、Signage設置場所でControllerの現在地取得ボタンを押します。保存する位置はその時点の位置で、自動追跡はしません。別の場所から操作するときは緯度・経度を手動で入力できます。

駅までの直線距離に迂回係数1.3を掛け、指定した徒歩速度で時間を推定します。手動の追加時間と乗車までの余裕時間を加え、その時刻以降に発車する便を表示します。実際の徒歩経路・信号・階段・入口位置には対応していないため、設置場所に応じて余裕時間を調整してください。駅の座標が取得できない場合は手動時間だけを使い、その旨をSignageに表示します。

## スクロール文面と切り替え効果

文面を書いた後、装飾したい文字を選択し、色・Regular/Bold・書体・点滅・区間末尾で停止する秒数を指定して「選択した文字に適用」を押します。選択した区間の末尾が画面中央に来ると指定秒数停止します。文全体の速度は10〜300px/秒で設定できます。文面全体を編集すると装飾はリセットされます。文字数は2000文字、装飾区間は200までです。

乗り物が入れ替わる際の効果は、上にスライド／フェード／立体フリップ／パタパタ表示／ズームから選びます。「なし」も選択できます。端末の「視差効果を減らす」など動きを抑える設定が有効な場合は、切り替え効果・点滅・スクロールを止め、文面を静止表示します。
